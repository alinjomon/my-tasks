# My Tasks — Personal Todo

A simple responsive todo list built with HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` in your browser.

## Features
- Add, edit, complete and delete tasks
- Filter all, pending and completed tasks
- Clear completed tasks
- Automatically saves tasks in browser LocalStorage

## Note
Tasks are stored only in the browser and device where you use the website. They do not sync between devices.
